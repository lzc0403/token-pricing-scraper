三、问题与建议

  • 渠道标签缺失：腾讯云国际站同一个 DeepSeek 模型存在「原厂直供」和「腾讯云自建」两条报价，但项目只按 source=tencent 一条记录。建议抓取时增加 channel_type 或 supplier 字段，把「原厂直供 / 腾讯云自建」写入记录。
  • 部分模型未收录：Hy3、GLM-5、GLM-5V-Turbo、GLM-5-Turbo、Kimi K2.7 Code HighSpeed、Hy-MT2-Plus 在项目中没有对应数据。
  • 部分价格不一致：DeepSeek-v3.2（截图 0.57 vs 项目 0.28）、GLM-5.2/5.1、Kimi K3 与截图不符，可能是截图页面为其他区域/版本，或项目数据已过期。
  • 截图来源推测：从布局与「原厂直供 / 腾讯云自建」标签看，截图大概率来自 腾讯云国际站 Model Studio，而非当前 GitHub Pages 站点。
