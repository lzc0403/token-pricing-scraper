# 大模型报价监控与监督系统 · 需求说明

## 一、系统定位
持续监控国内外大模型厂商的官方原厂价与渠道商报价，识别官方调价、监督国内渠道价是否同步跟进，并通过飞书与网页双通道呈现结果。

## 二、关键术语（消歧义）
- **官方原厂价**：厂商官网 API 定价页公布的当前生效原价。
- **渠道价**：第三方云厂商 / 聚合站（腾讯云、阿里云、火山、OpenRouter 等）的转售挂牌价。
- **官方调价**：官方原厂价任一计费字段（输入、输出、缓存读取、缓存创建/存储）发生变动，即记一次调价。
- **渠道跟进**：官方调价后，渠道价按同方向、相近幅度作出调整。

## 三、监控范围与定价规则
1. 国内大模型：同时采集并展示官方原厂价与渠道价。
2. 国外大模型：仅采集并展示官方原厂价，不展示渠道价。
3. 所有模型：官方原厂价逐日落盘，留存完整历史记录，可回溯。

## 四、对比与校验逻辑
1. 定价基准：所有报价一律以官方原厂价为唯一基准，进行溢价/合理性比对。
2. 渠道跟进监督：官方调价发生后，对比国内各渠道商报价是否随动，输出「已跟进 / 未跟进 / 幅度背离」三类结论。
3. 运行方式：作为独立「报价监督」任务每日持续执行。

## 五、通知与展示机制
1. 官方调价：检测到立即经飞书模板消息通知（含模型、厂商、字段、旧价→新价、幅度、日期）。
2. 渠道监督结果：国内渠道价是否同步调整的结论，同样经飞书通知。
3. 网页端：价格变动与监督结果同步可视化——调价横幅、详情徽章、渠道跟进状态标记。

## 六、复核与检验要点
- 定价基准唯一性（是否全以官方原厂价为准）
- 历史记录完整性（无断档、可回溯）
- 调价识别准确性（无漏报、无误报、无编造）
- 渠道对比逻辑正确性（跟进判断标准清晰、可复现）
- 飞书通知触发正确性（应发必发、不应发不发）
