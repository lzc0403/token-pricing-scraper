## 官方调价专门预警（18:15）

用户要求：「针对所有大模型的官方价格，进行价格调整的时候，你要加入一个专门的预警，方便我进行跟进处理」。
经 AskUserQuestion 确认形式：**在日报里加置顶专属区块**（非独立消息）。

### 为什么必须新增（旧逻辑的缺口）

旧 `_build_reminders` 规则 0a 只在「官网调价 **且** 渠道未跟进」时才发 🚨 市场行情警报；
**渠道同幅跟进的官方调价被静默归为「正常播报」**——官方价是定价锚点，用户需要跟进每一条，
不能因为渠道跟上了就看不见。

### 实现

- `core/notifier.py:_official_price_alerts(deltas)`：筛 `is_official_source` 为 True 的
  delta，**无条件列出**（与 `_market_analysis` 的 official_lead 职责分离），按最大幅度降序。
- `_official_alert_lines(alerts)`：文本/卡片共用的行渲染，**跟进状态按字段判定**
  （同一模型可能输入价已同步、缓存写入价未同步，模型级笼统结论会误导跟进）。
- `build_message`：表格前插入 `🏛️ 官方调价（N 个模型，需跟进）`。
- `build_card`：KPI 行后、总表前插入预警 div（无 alert 时不插入，表头照常输出）。
- 顺带补 `_FIELD_LABEL` / `_FIELD_ORDER` 的 `cache_hit`/`cache_write`（此前缺失，
  表格里 cache_write 显示英文原字段名且排序掉到最后）；SOURCE_LABELS 补 gemini/grok。

### 输出样例

```
🏛️ 官方调价（3 个模型，需跟进）
• GPT-5.6 Sol · OpenAI官网
    ├ 输入 $4→$5 ↑25%｜渠道同步：OpenRouter
    └ 缓存写入 $5→$6 ↑20%｜渠道同步：未见（需人工确认）
• Claude Opus 5 · Anthropic官网
    └ 输入 $5→$4 ↓20%｜渠道同步：OpenRouter
```

### 已知数据限制

deltas 只含**变动**记录，无法区分「渠道存在但未调价」与「该模型无此渠道」，
故未同步时措辞为「未见（需人工确认）」，不臆断渠道状态。
